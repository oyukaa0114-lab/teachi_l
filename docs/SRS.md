## 1. Танилцуулга

### 1.1 Зорилго

Энэхүү баримт бичиг нь **Teachi_l** — сургалтын байгууллагад зориулсан багшийн үнэлгээний удирдлагын системийн програм хангамжийн шаардлагыг тодорхойлно. IEEE 830 стандартад нийцүүлэн бэлтгэсэн.

### 1.2 Хамрах хүрээ

Teachi_l нь дараах боломжийг олгоно:

- Оюутан багшийнхаа үнэлгээг оруулах
- Багш өөрийн үнэлгээ, санал хүсэлтийг харах, хариу өгөх
- Администратор үнэлгээний хугацааг удирдах, тайлан гаргах
- Супер администратор системийн бүх мэдээллийг хянах, AI тусламжтайгаар контент модерация хийх

Систем нь вэб, iOS, Android, macOS, Windows платформ дээр ажиллана.

### 1.3 Товчилсон үгийн тайлбар

| Товчилсон үг | Тайлбар |
|---|---|
| SRS | Software Requirements Specification |
| UI | User Interface (Хэрэглэгчийн интерфэйс) |
| API | Application Programming Interface |
| AI | Artificial Intelligence (Хиймэл оюун) |
| CRUD | Create, Read, Update, Delete |
| SPA | Single Page Application |

### 1.4 Лавлах баримт бичгүүд

- Flutter SDK 3.8.0 баримт бичиг
- Supabase баримт бичиг
- Groq API баримт бичиг (Llama-3.3-70b-versatile)
- Material Design 3 загварын удирдамж

## 2. Ерөнхий тодорхойлолт

### 2.1 Бүтээгдэхүүний тойм

Teachi_l нь их дээд сургууль болон ерөнхий боловсролын байгууллагуудад зориулсан цахим үнэлгээний платформ юм. Систем нь 4 түвшний хэрэглэгчийн эрхтэй:

```
Супер Администратор
       │
  Администратор
       │
    Багш ←──── Оюутан
```

### 2.2 Бүтээгдэхүүний функц (ерөнхий)

- **Аутентификаци:** Нэвтрэх нэр/нууц үгээр нэвтрэх, эрхэд суурилсан чиглүүлэлт
- **Үнэлгээ:** Оюутан багшийг 1–5 одоор үнэлж, сэтгэгдэл бичих
- **Хариу мэдэгдэл (Feedback):** Хичээлийн агуулга, бүтцийн талаарх санал хүсэлт
- **Өргөдөл/Гомдол:** Дэмжлэгийн хүсэлт илгээх, явцыг хянах
- **Тайлан:** Excel тайлан автоматаар үүсгэх
- **Мэдэгдэл:** Бодит цагийн мэдэгдлийн систем
- **AI Модерация:** Зохисгүй агуулгыг автоматаар илрүүлж устгах

### 2.3 Хэрэглэгчийн ангилал

| Хэрэглэгч | Тоо | Дүрслэл |
|---|---|---|
| Оюутан | Олон | Эрдэм шинжилгээний ажилтан, бакалавр/магистр |
| Багш | Олон | Судлагдахуун заадаг боловсролын ажилтан |
| Администратор | Цөөн | Тэнхим/сургуулийн менежмент |
| Супер Администратор | 1–2 | Бүх системийг хариуцсан администратор |

### 2.4 Үйл ажиллагааны орчин

- **Frontend:** Flutter 3.8.0 (Dart)
- **Backend:** Supabase (PostgreSQL + Auth + Edge Functions)
- **AI Сервис:** Groq API (Llama-3.3-70b-versatile)
- **Платформ:** Web, iOS, Android, macOS, Windows

### 2.5 Загварчлалын хязгаарлалт

- Нууц үгийг SHA-256 алгоритмаар хаш хийнэ
- Интернэт холболт шаардагдана (Supabase ба Groq API)
- `.env` файлаар орчны хувьсагч (GROQ_API_KEY) удирдана

## 4. Системийн функциональ шаардлага

### 4.1 Аутентификаци модуль

**FR-AUTH-01:** Систем нэвтрэх нэр (username) ба нууц үгийн хосыг баталгаажуулна.  
**FR-AUTH-02:** Нууц үгийг SHA-256 алгоритмаар хаш хийж хадгална.  
**FR-AUTH-03:** Нэвтрэлт амжилттай болмогц хэрэглэгчийн дүрд тохирсон dashboard руу чиглүүлнэ.  
**FR-AUTH-04:** Session-г SharedPreferences-т хадгалж, дараагийн нэвтрэлтэд автоматаар ашиглана.  
**FR-AUTH-05:** Систем буруу нэвтрэлтийн оролдлогод монгол хэл дэх алдааны мэдэгдэл харуулна.

### 4.2 Үнэлгээний модуль

**FR-EVAL-01:** Оюутан идэвхтэй үнэлгээний хугацаанд л үнэлгээ өгч чадна.  
**FR-EVAL-02:** Үнэлгээ нь 1–5 оддын рейтинг ба заавал биш сэтгэгдэл агуулна.  
**FR-EVAL-03:** Оюутан нэг хугацаанд нэг багшид давтан үнэлгээ өгч болохгүй.  
**FR-EVAL-04:** Оюутан анонимаар үнэлгээ өгөх сонголт хийж чадна.  
**FR-EVAL-05:** Үнэлгээ хадгалагдсаны дараа AI модерацийн edge function автоматаар ажиллана.

### 4.3 AI Контент Модерацийн модуль

**FR-MOD-01:** Үнэлгээ үүсэхэд Supabase trigger Edge Function-г дуудна.  
**FR-MOD-02:** Edge Function нь Groq API-г (Llama-3.3-70b-versatile) ашиглан сэтгэгдлийг дүн шинжилгээ хийнэ.  
**FR-MOD-03:** Систем доорх контентийг зохисгүй гэж тодорхойлно:
  - Доромжлох үг хэллэг
  - Далдаалсан бүдүүлэг үг
  - Дарамт шахалт
  - Заналхийлэл
  
**FR-MOD-04:** Зохисгүй гэж тодорхойлогдсон үнэлгээг системээс автоматаар устгана.  
**FR-MOD-05:** Устгасан тохиолдолд оюутанд мэдэгдэл илгээнэ.  
**FR-MOD-06:** Зөвшөөрөгдсөн сэтгэгдлийг позитив/негатив/нейтрал гэж сентимент шинжилгээ хийнэ.

### 4.4 Тайлан гаргах модуль

**FR-REP-01:** Систем дараах 4 хуудастай Excel тайлан үүсгэнэ:
  1. Дүнгийн хуудас — ерөнхий статистик (дундаж оноо, тархалт)
  2. Багшийн үнэлгээ — багш тус бүрийн гүйцэтгэл
  3. Бүх үнэлгээ — бүрэн жагсаалт
  4. Оюутны жагсаалт — оролцогч оюутнууд

**FR-REP-02:** Тайланг үнэлгээний хугацаагаар шүүж гаргаж чадна.  
**FR-REP-03:** Тайланг сургуулиар шүүж гаргаж чадна.  
**FR-REP-04:** Тайланг тэнхимээр шүүж гаргаж чадна.  
**FR-REP-05:** Вэб дээр тайланг браузероор татаж авна; мобайл дээр локал файлд хадгалж нээнэ.

### 4.5 Мэдэгдлийн модуль

**FR-NOT-01:** Систем шинэ үйл явдал бүрт холбогдох хэрэглэгчид мэдэгдэл үүсгэнэ.  
**FR-NOT-02:** Supabase PostgresChanges ашиглан мэдэгдлийн тоог бодит цагт шинэчилнэ.  
**FR-NOT-03:** Хэрэглэгч мэдэгдлийг уншсан гэж тэмдэглэж чадна.  
**FR-NOT-04:** Мэдэгдлийн жагсаалт огноогоор буурах дарааллаар харагдана.

### 4.6 Хүсэлт/Гомдлын модуль

**FR-REQ-01:** Оюутан гурван ангиллаар хүсэлт илгээнэ: эрдэм шинжилгээний, захиргааны, орчны.  
**FR-REQ-02:** Хүсэлтэд файл хавсаргаж илгээж болно.  
**FR-REQ-03:** Хүсэлтийн статус дараах төлөвтэй байна: илгээсэн → шийдвэрлэж байна → шийдвэрлэсэн.  
**FR-REQ-04:** Администратор болон оюутан хүсэлтийн чат хэлбэрийн харилцаа явуулна.

### 4.7 Үнэлгээний хугацааны модуль

**FR-PER-01:** Администратор үнэлгээний хугацаа үүсгэж (нэр, эхлэх огноо, дуусах огноо) болно.  
**FR-PER-02:** Зэрэгцэн хэд хэдэн үнэлгээний хугацаа идэвхтэй байж болно.  
**FR-PER-03:** Систем хугацаа дуусмагц үнэлгээ хаана.

## 5. Функциональ Бус Шаардлага

### 5.1 Гүйцэтгэл

**NFR-PERF-01:** Нэвтрэх хуудас 3 секундэд ачаалагдана (энгийн сүлжээний нөхцөлд).  
**NFR-PERF-02:** Dashboard 5 секундэд бүрэн ачаалагдана.  
**NFR-PERF-03:** Excel тайлан 10,000 мөр хүртэлх өгөгдөлд 30 секундэд үүснэ.  
**NFR-PERF-04:** AI модерацийн хариу 10 секундэд ирнэ.

### 5.2 Найдвартай байдал

**NFR-REL-01:** Систем 99% uptime-г баталгаажуулна (Supabase SLA-д тулгуурлан).  
**NFR-REL-02:** Сүлжээний алдааны үед хэрэглэгчид ойлгомжтой алдааны мэдэгдэл харуулна.  
**NFR-REL-03:** Session дуусмагц хэрэглэгчийг нэвтрэх хуудас руу автоматаар чиглүүлнэ.

### 5.3 Аюулгүй байдал

**NFR-SEC-01:** Нууц үгийг SHA-256 алгоритмаар хаш хийж, plaintext хэлбэрээр хадгалахгүй.  
**NFR-SEC-02:** Бүх API хүсэлт Supabase JWT token-р баталгаажна.  
**NFR-SEC-03:** Хэрэглэгч зөвхөн өөрийн эрхэд тохирсон мэдээллийг харж чадна (Row Level Security).  
**NFR-SEC-04:** GROQ_API_KEY нь `.env` файлд хадгалагдаж, репозиторид commit хийгдэхгүй.  
**NFR-SEC-05:** Edge Function Supabase тал дээр аюулгүй орчинд ажиллана.

### 5.4 Хэрэглээний хялбар байдал

**NFR-USE-01:** UI нь монгол хэл дээр бүрэн харагдана.  
**NFR-USE-02:** Алдааны мэдэгдэл хэрэглэгчид ойлгомжтой монгол хэлээр харагдана.  
**NFR-USE-03:** Систем Material Design 3 стандартад нийцсэн UI ашиглана.  
**NFR-USE-04:** Responsive дизайн — дэлгэцийн хэмжээнд автоматаар тохирно.

### 5.5 Дэмжигдэх чадвар

**NFR-MAINT-01:** Кодыг features/ хавтсаар (auth, students, teachers, admin, super_admin) ангилна.  
**NFR-MAINT-02:** Дата хандалтыг repositories/ давхаргаар тусгаарлана.  
**NFR-MAINT-03:** Core сервисүүдийг core/services/ хавтсад байрлуулна.

### 5.6 Платформ нийцтэй байдал

**NFR-PORT-01:** Вэб: Chrome, Firefox, Edge сүүлийн хувилбарт ажиллана.  
**NFR-PORT-02:** Мобайл: iOS 13+, Android 8.0+ дэмжинэ.  
**NFR-PORT-03:** Desktop: macOS 10.15+, Windows 10+ дэмжинэ.
